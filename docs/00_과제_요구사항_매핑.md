## 완주 체크리스트

- [x] 가입·로그인·로그아웃이 되고, 로그인 없이 자료 화면을 열면 로그인 화면이 나온다. (구현 완료 — 실제 배포에서 확인 필요)
- [x] 저장된 비밀번호에 입력한 글자가 보이지 않는다. (Supabase Auth가 해싱 — Table Editor의 `auth.users`에는 비밀번호 원문이 아예 노출되지 않음)
- [ ] 로그아웃 뒤 같은 값으로 다시 요청하면 거절된다. (`verify.sh` (2)로 실측 필요)
- [ ] 남의 자료를 읽기·수정·삭제하려는 요청이 양방향으로 모두 거절되고, 목록에도 섞이지 않는다. (RLS로 설계됨 — `verify.sh` (3)(4)(5)로 실측 필요)
- [ ] 설명서 여섯 항목이 나뉘어 있고, ⑥이 비어 있지 않다. (`docs/07_인증구현설명서.md` — ④는 실측 채워 넣기 전까지 미완)
- [ ] 서로 다른 날짜 5일의 기록과 3일차 전 규칙 변경이 순서대로 있다. (`작업내역_체크리스트.md`의 T07 5일 사용 기록표 참고 — 진행 예정)
- [x] 제출물에 비밀번호·토큰·비밀키 원문이 없다. (`config.js`엔 anon key만 — 비밀값 아님. `verify.sh`/설명서엔 가리기 지침 명시)

## 아직 실측하지 못한 이유 (정직하게 남김)

이 문서와 코드는 AI가 설계·구현했지만, 실제 배포된 Supabase 프로젝트에 대해 로그인 요청을 보내 응답을 받는 작업(`verify.sh` 실행, 브라우저 개발자 도구 캡처)은 실제 계정 자격 증명과 배포 환경 접근이 필요해 AI가 대신할 수 없다. 학생이 `verify.sh`를 실행하고 `docs/07_인증구현설명서.md` ④를 채워야 카드 2~4가 완전히 통과된다.
