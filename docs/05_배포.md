## Supabase 프로젝트 설정 절차

1. https://supabase.com 에서 새 프로젝트 생성 (무료 티어로 충분 — 500MB DB, 50,000 MAU).
2. 프로젝트 대시보드 → **SQL Editor**에서 `supabase-schema.sql` 전체 내용을 붙여넣고 실행 (`records`/`rule_changes` 테이블, RLS 정책, `delete_my_account` 함수 생성).
3. **Project Settings → API**에서 `Project URL`과 `anon public` key를 복사.
4. `config.js`의 `SUPABASE_URL`, `SUPABASE_ANON_KEY`를 위 값으로 교체.
5. (선택) **Authentication → Providers → Email**에서 "Confirm email" 옵션을 끄면 가입 즉시 로그인되어 테스트가 편해진다. 켜두면 실제 서비스에 더 가까운 흐름(이메일 확인 필요)이 된다.

## Vercel 배포 절차

```bash
# 1. 로컬에서 커밋
git add .
git commit -m "T07: Supabase Auth 연동, plan-do-see로 이름 변경"
git push origin main

# 2. Vercel 대시보드에서 이 GitHub 저장소를 Import
#    - Framework Preset: Other (빌드 없음)
#    - Build Command: 비워둠
#    - Output Directory: 루트(.)
# 3. Deploy
```

`main` 브랜치에 push할 때마다 Vercel이 자동으로 재배포한다.
